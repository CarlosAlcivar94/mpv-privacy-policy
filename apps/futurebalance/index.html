FutureBalance

Planificacion financiera manual para ver gastos, tarjetas y pagos futuros con orden.

FutureBalance esta pensada para quienes quieren controlar su dinero sin conectar bancos: registrar movimientos, separar carteras, revisar tarjetas, anticipar pagos y proyectar el saldo disponible con una lectura simple.

Movimientos Ingresos, gastos, transferencias y ajustes manuales por cartera.
Tarjetas y pagos Control de cuotas, fechas, deudas y compromisos futuros.
Presupuesto Categorias, limites y reportes para entender el flujo de dinero.
Privacidad Sin conexion bancaria; politica, manual y eliminacion de cuenta publicas.
