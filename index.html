Politica de Privacidad

Ultima actualizacion: 24 de abril de 2026

Esta aplicacion ("MPV") respeta tu privacidad. Esta politica explica que datos recopilamos, como los usamos y que opciones tienes.

1. Datos que recopilamos

Podemos recopilar y procesar:

  • Datos de cuenta: correo electronico e identificador de usuario (autenticacion).
  • Datos que registras en la app: vehiculos, mantenimientos, gastos, repostajes, documentos y adjuntos.
  • Datos tecnicos basicos para funcionamiento y seguridad del servicio.

2. Uso de la camara

La aplicacion solicita el permiso android.permission.CAMERA para que puedas:

  • Tomar fotos de perfil de vehiculos.
  • Adjuntar fotos o documentos a registros dentro de la app.

El uso de la camara es iniciado por ti y solo cuando eliges tomar una foto.

3. Servicios de terceros (Firebase / Google)

Usamos servicios de Google/Firebase para operar la aplicacion:

  • Firebase Authentication (inicio de sesion).
  • Cloud Firestore (almacenamiento de datos de la app).
  • Firebase Storage (archivos y adjuntos).
  • Google Play Billing (compras dentro de la app, si aplica).
  • Google Mobile Ads (anuncios para ciertos planes, si aplica).

Estos proveedores pueden procesar datos conforme a sus propias politicas de privacidad.

4. Comparticion de datos

  • No vendemos tus datos personales.
  • Los datos se comparten unicamente con proveedores necesarios para prestar el servicio.

5. Conservacion y eliminacion de datos

  • Conservamos tus datos mientras uses la app o sea necesario para prestar el servicio.
  • Puedes solicitar eliminacion de tu cuenta y datos escribiendo a:
    Contacto: ka94desarrollo@gmail.com

6. Seguridad

Aplicamos medidas razonables para proteger la informacion, pero ningun sistema es 100% infalible.

7. Cambios a esta politica

Podemos actualizar esta politica ocasionalmente. Publicaremos la version vigente con su fecha de actualizacion.
