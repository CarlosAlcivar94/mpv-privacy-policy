Referencias oficiales: User Data policy, Data safety y eliminacion de cuenta.

1. Una app, una politica

Cada politica debe mencionar el nombre visible, paquete Android, datos tratados, terceros, permisos, anuncios, compras, backups, seguridad y contacto.

2. Manual aparte

El manual explica uso del producto. La politica no debe mezclar instrucciones de uso con declaraciones de privacidad.

3. Actualizar por cambio real

Si agregas SDKs, permisos, anuncios, compras, Drive, Storage o una nueva fuente de datos, actualiza la politica y el formulario Data safety.
