Manual de Uso de MPV

Guia basica para empezar rapido

Inicio Politicas

1. Primer ingreso

  1. Abre la aplicacion MPV.
  2. Inicia sesion o crea una cuenta nueva.
  3. Completa tu perfil basico para personalizar tu experiencia.

2. Crear un vehiculo

  1. Ve a la seccion Vehiculos.
  2. Toca Agregar vehiculo.
  3. Completa los datos principales: nombre, placa, marca y modelo.
  4. Guarda el registro.

3. Registrar mantenimiento

  1. Selecciona un vehiculo.
  2. Ingresa a Mantenimientos.
  3. Presiona Nuevo mantenimiento y agrega fecha, kilometraje y costo.
  4. Adjunta comprobantes si lo necesitas.

4. Controlar gastos y repostajes

  • Registra cada gasto para llevar un historial ordenado.
  • Agrega litros y precio en cada repostaje.
  • Revisa reportes para analizar consumo y costos por periodo.

5. Adjuntar fotos o documentos

Puedes tomar fotos desde la camara o seleccionar archivos desde tu dispositivo para guardarlos dentro de cada registro.

Consejo: registra cada movimiento el mismo dia para mantener tus reportes precisos.
