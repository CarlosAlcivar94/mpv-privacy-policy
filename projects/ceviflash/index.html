CEVIFLASH

PWA para convertir la operacion diaria de un negocio pequeno en un flujo ordenado de inventario, platos, venta y caja.

Resumen

CEVIFLASH administra compras, proveedores, insumos, inventario, platos, recetas, ventas, cierres de caja, gastos, usuarios y reportes desde una aplicacion web instalable como PWA.

Angular TypeScript Firebase Auth Firestore PWA Roles

Problema que resuelve

Un negocio que compra insumos, arma productos, vende a diario y registra gastos necesita saber stock, costo, margen, caja y utilidad sin depender de hojas sueltas ni calculos manuales. CEVIFLASH convierte ese flujo en pantallas simples para operar.

  • Inventario con compras, proveedores, stock y costo promedio.
  • Platos y recetas para estimar costo y margen.
  • Venta rapida con descuento de inventario.
  • Cierre diario de caja por metodo de pago.
  • Gastos y reportes para utilidad aproximada.
  • Usuarios con roles de operador, inventario y administrador.

Enfoque movil

La app se redistribuyo para que el primer flujo despues del login sea venta/caja. En telefono usa navegacion compacta, pestanas internas y una experiencia instalable mediante PWA.

Resultado presentable

El proyecto muestra una aplicacion completa de operacion comercial: autenticacion, roles, Firestore, reglas de seguridad, datos en tiempo real, reportes, PWA y despliegue en Firebase Hosting. Para el portafolio se omiten identificadores internos, usuarios, configuracion de Firebase y datos reales del negocio.
