Resumen

ACKA94 es una plataforma privada para administrar usuarios, planes, soporte, avisos, roles, politicas de version, entregas controladas y auditoria de las aplicaciones conectadas al ecosistema KA94 Studio.

Problema que resuelve

Cuando varias apps tienen usuarios, planes, soporte, anuncios y reglas de version, administrarlas desde pantallas separadas vuelve lento el soporte y dificulta tener trazabilidad. ACKA94 centraliza esas tareas en un panel privado con permisos.

  • Catalogo de aplicaciones administradas.
  • Gestion de usuarios, beneficios y planes.
  • Atencion de tickets de soporte.
  • Avisos y comunicados para usuarios.
  • Politicas de version por aplicacion.
  • Registro de auditoria para acciones administrativas.

Apps conectadas

El centro administrativo esta preparado para operar con My Vehicle Planner y futuras aplicaciones como FutureBalance, manteniendo una base comun de soporte y control interno.

Acceso privado: acka94.web.app.

Resultado presentable

La solucion funciona como una capa administrativa interna para crecer el portafolio sin perder control sobre usuarios, soporte, versiones y beneficios. Es un proyecto privado, por eso el portafolio muestra el caso de uso sin publicar accesos ni datos operativos.
