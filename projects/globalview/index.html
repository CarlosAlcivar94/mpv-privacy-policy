GLOBALVIEW

Portal interno para centralizar acceso, administracion y trazabilidad sobre reportes Power BI.

Resumen

GLOBALVIEW es un portal PHP para controlar el acceso a reportes Power BI desde una estructura administrable por base de datos. Permite gestionar usuarios, roles, permisos, reportes, sesiones, notificaciones y auditoria operativa.

PHP MySQL Power BI DataTables Seguridad Auditoria

Problema que resuelve

Cuando los reportes crecen, no basta con compartir enlaces. Se necesita saber quien puede ver cada reporte, administrar altas y bajas, registrar eventos sensibles y mantener una experiencia unica para usuarios lectores y administradores.

  • Login y roles para administradores, gestores y lectores.
  • Menu de reportes construido desde base de datos.
  • Permisos individuales y masivos por reporte.
  • Visor con marca de agua y registro de acceso.
  • Notificaciones para seguridad, solicitudes y eventos de impresion.
  • Timeout de sesion configurable desde el portal.

Criterio tecnico

El proyecto evoluciono desde un template y componentes heredados hacia un runtime enfocado en reportes, con modulos de administracion, helpers, controladores, assets por pagina y una estrategia gradual para reducir regresiones.

Resultado presentable

GLOBALVIEW demuestra experiencia en plataformas internas con permisos, auditoria, administracion de reportes y endurecimiento progresivo. El portafolio usa el nombre GLOBALVIEW y no publica datos institucionales, rutas internas, credenciales, hosts, nombres de bases de datos ni endpoints privados.
