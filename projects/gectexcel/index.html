GeCTExcel

Servicio interno para que varios archivos Excel consuman una API externa sin compartir credenciales ni invalidar tokens.

Portafolio SATURNO BI Contacto

Resumen

GeCTExcel centraliza autenticacion, cache de token, renovacion anticipada, reintento controlado y proxy de consultas. Excel deja de guardar usuarios, contrasenas o tokens y solo llama al servicio interno.

FastAPI Uvicorn HTTPX Excel/VBA Windows tasks Watchdog

Problema que resuelve

La API externa permite un solo token activo por usuario. Cuando varios Excel solicitaban token por separado, una consulta podia invalidar la sesion de otra. La solucion mueve la autenticacion fuera de Excel y la controla desde un servicio.

  • Login centralizado contra API externa.
  • Cache de token con bloqueo de archivo.
  • Renovacion antes del vencimiento.
  • Proxy de endpoints usados por Excel.
  • Reintento controlado ante 401/403.
  • Watchdog y arranque automatico en Windows.

Arquitectura

Excel -> Servicio interno -> API externa

Los secretos viven en variables de entorno y archivos locales no versionados. Los logs evitan registrar tokens completos.

Resultado presentable

La integracion reduce fallos por tokens, evita distribuir credenciales dentro de hojas Excel y permite operar el servicio en un servidor existente con health check, tareas programadas, watchdog y pruebas locales sin tocar la API real.
